## Implementation rules
1. Each service page owns its commercial/service-intent cluster. Do not create a second service page targeting the same primary phrase.
2. Each guide owns informational intent (how, what, checklist, planning, examples). It should explain the problem and link contextually to its matching service page.
3. Use close variants naturally in visible copy, headings and FAQs only where they answer a real customer question. Do not repeat exact-match phrases unnaturally.
4. Keep platform-specific advertising terms (Google, Facebook/Meta, TikTok) within the advertising page; keep the creative page about design deliverables, not ad buying.
5. Keep website chatbot queries separate from internal workflow automation / agent queries.
6. Do not create location doorway pages or thin keyword pages for every city. Mention Pakistan and service coverage accurately; expand geography only when there is genuinely distinct, useful local content.
7. Do not add search-volume, KD, ranking, lead, or “low competition” claims until verified from a suitable data source.

## Measurement and next validation
- Recheck GSC after the 3 November deployment has had time to be crawled and data finalized (approximately 6 November or later).
- Review query-to-page mapping: one relevant service URL should lead each commercial query cluster; investigate if unrelated URLs alternate for the same query.

- Obtain Ahrefs keyword metrics only if the account plan supports them, or use another legitimate source. Record the source, country, date and limitations.
- Prioritize phrases that have relevant impressions, commercial intent and a realistic SERP fit—not merely the largest volume.
